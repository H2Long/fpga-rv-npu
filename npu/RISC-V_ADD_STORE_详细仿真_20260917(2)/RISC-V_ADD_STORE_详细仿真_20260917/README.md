# ADD 与 STORE 指令运行过程

基于最新下载代码 `0bca94a`（2026-09-14），分别仿真 **一条 ADD** 和 **一条 STORE（SW）**。两个测试均 PASS。

## NPU 子目录（2026-09-17 新增）

`npu/` 内为按根目录五份 npu_*.md 设计文档完成的 **INT8 矩阵乘法加速器 RTL 全实现**
（45 个功能模块 + 测试台，Icarus Verilog 仿真 7/7 PASS），含架构图/波前图/实测波形图，
详见 `npu/docs/npu_实现说明.md`。

`波形图片/` 中：

前四张为 **3200×1800、16:9**，每张可直接放一页 PPT。后两张为 3200×3600，便于放大查看全部信号。所有图片都有 SVG 矢量版本。

图片直接绘制本次 RTL 仿真产生的 VCD 跳变。顶部为目标指令推进顺序；绿色底色定位目标指令的相关信号区间。数据以十六进制显示。

## 两条指令

- ADD：`add x3,x1,x2`，`0x12 + 0x23 = 0x35`；95 ns 写入 x3。
- STORE：`sw x2,12(x1)`，向字节地址 `0x0080000C` 写入 `0x12345678`；85 ns 更新 DTCM[3]。

测试台提前设置寄存器和内存初值，40 ns 释放复位。每次只有 PC=0 的一条目标指令，后面填充 NOP；这样能直接跟踪这条指令经过各模块的过程。

## 复现

安装 Python、Matplotlib 和 Icarus Verilog；将 `iverilog`、`vvp` 加入 PATH。在解压后的本文件夹中运行：

```powershell
python run.py
python render.py
```

脚本会生成临时 `build/`，仅在编译副本中替换作者机器的两个初始化文件路径，不改变 RTL 逻辑。原始代码保留在 `rtl_original/`。

这是 RTL 仿真，非板上采集；10 ns 时钟周期是仿真设置。
