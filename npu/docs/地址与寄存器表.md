# NPU v2.0 地址与寄存器表

本文档描述当前 `npu_system` 的 CPU MMIO 地址空间、控制寄存器、状态寄存器和三块片上 Buffer。

## 1. CPU MMIO 接口

```text
cpu_addr[31:0]
cpu_wdata[31:0]
cpu_byte_en[3:0]
cpu_we
cpu_valid
cpu_rdata[31:0]
cpu_ready
```

地址按字节寻址，32 位访问通常按 4 字节对齐。

一次访问的基本流程：

```text
cpu_valid=1
    -> mmio_if 锁存请求
    -> 目标寄存器或 Buffer 执行访问
    -> cpu_ready=1 一个时钟周期
```

CPU 检测到 `cpu_ready=1` 后，应撤销当前 `cpu_valid`，避免同一请求被再次采样。

## 2. 地址空间总览

| 地址范围 | 类型 | 大小 | 说明 |
|---|---|---:|---|
| `0x0000_0000 ~ 0x0000_001F` | 控制寄存器 | 32 B | 配置参数和启动命令 |
| `0x0000_0020 ~ 0x0000_002F` | 状态寄存器 | 16 B | 运行状态 |
| `0x0000_1000 ~ 0x0000_10FF` | A Buffer 窗口 | 256 B | 64 个 32 位字 |
| `0x0000_2000 ~ 0x0000_20FF` | BT Buffer 窗口 | 256 B | 64 个 32 位字 |
| `0x0000_3000 ~ 0x0000_33FF` | C Buffer 窗口 | 1 KB | 256 个 32 位字 |

未列出的地址属于保留地址，当前不应访问。

## 3. 控制寄存器

### 3.1 `CTRL`：启动和完成清除

地址：`0x0000_0000`

| 位 | 名称 | 读写 | 复位/读值 | 说明 |
|---:|---|---|---:|---|
| 0 | `start` | W | 0 | 写 1 产生一次 `start_req` |
| 1 | `clear_done` | W | 0 | 写 1 请求清除 DONE 状态 |
| 31:2 | 保留 | - | 0 | 写入无效 |

`CTRL` 是命令寄存器，不保存 bit0/bit1。读取 `0x0000` 始终返回 0。

常用写值：

```text
0x0000_0001：启动任务
0x0000_0002：清除 DONE
0x0000_0003：同时请求启动和清除 DONE
```

### 3.2 `M_CFG`：矩阵行数

地址：`0x0000_0004`

| 位 | 名称 | 读写 | 复位值 | 有效范围 |
|---:|---|---|---:|---:|
| 5:0 | `M` | R/W | 4 | 1~63 |
| 31:6 | 保留 | - | 0 | - |

### 3.3 `N_CFG`：矩阵列数

地址：`0x0000_0008`

| 位 | 名称 | 读写 | 复位值 | 有效范围 |
|---:|---|---|---:|---:|
| 5:0 | `N` | R/W | 4 | 1~63 |
| 31:6 | 保留 | - | 0 | - |

### 3.4 `K_CFG`：内积长度

地址：`0x0000_000C`

| 位 | 名称 | 读写 | 复位值 | 有效范围 |
|---:|---|---|---:|---:|
| 5:0 | `K` | R/W | 4 | 1~63 |
| 31:6 | 保留 | - | 0 | - |

### 3.5 `TK_CFG`：K 方向 Tile 大小

地址：`0x0000_0018`

| 位 | 名称 | 读写 | 复位值 | 有效范围 |
|---:|---|---|---:|---:|
| 4:0 | `TK` | R/W | 4 | 1~16 且不大于 K |
| 31:5 | 保留 | - | 0 | - |

### 3.6 `QUANT_CFG`：量化右移位数

地址：`0x0000_001C`

| 位 | 名称 | 读写 | 复位值 | 说明 |
|---:|---|---|---:|---|
| 4:0 | `qshift` | R/W | 0 | 结果右移位数，0 表示不右移 |
| 31:5 | 保留 | - | 0 | - |

## 4. 状态寄存器

### 4.1 `STATUS`

地址：`0x0000_0020`

| 位 | 名称 | 读写 | 含义 |
|---:|---|---|---|
| 0 | `BUSY` | R | `1`：NPU 正在执行任务 |
| 1 | `DONE` | R | `1`：任务完成，可读取 C Buffer |
| 2 | 保留 | R | 固定为 0 |
| 3 | `BUFFER_READY` | R | `1`：CPU 可以访问 Buffer |
| 31:4 | 保留 | R | 读为 0 |

推荐判断顺序：

```text
先等待 BUSY=0
DONE=1 时读取 C Buffer
```

地址 `0x0000_0024` 保留，读取为 0。

## 5. A Buffer

地址窗口：`0x0000_1000 ~ 0x0000_10FF`

实际有效存储为 64 个 32 位字：

```text
有效地址：0x1000 + 4*i，i=0..63
内部字地址：(CPU地址 - 0x1000) >> 2
```

一个 32 位字的打包格式：

| 位段 | 内容 |
|---|---|
| `[7:0]` | A lane 0 |
| `[15:8]` | A lane 1 |
| `[23:16]` | A lane 2 |
| `[31:24]` | A lane 3 |

数据按 K 主序存放。对于一个 A Tile，地址基准为：

```text
A 字基址 = tile_i * K + tile_k * TK
```

## 6. BT Buffer

地址窗口：`0x0000_2000 ~ 0x0000_20FF`

实际有效存储为 64 个 32 位字：

```text
有效地址：0x2000 + 4*i，i=0..63
内部字地址：(CPU地址 - 0x2000) >> 2
```

BT 是 B 的转置矩阵，一个字的打包格式为：

| 位段 | 内容 |
|---|---|
| `[7:0]` | BT lane 0 |
| `[15:8]` | BT lane 1 |
| `[23:16]` | BT lane 2 |
| `[31:24]` | BT lane 3 |

BT Tile 地址基准为：

```text
BT 字基址 = tile_j * K + tile_k * TK
```

## 7. C Buffer

地址窗口：`0x0000_3000 ~ 0x0000_33FF`

实际有效存储为 256 个 32 位字：

```text
有效地址：0x3000 + 4*i，i=0..255
内部字地址：(CPU地址 - 0x3000) >> 2
```

每个字保存一个量化后的 C 元素，按行主序排列：

```text
C 字地址 = C_base + row * N + col
C_base   = tile_i * 4 * N + tile_j * 4
```

边界 Tile 中越界的 C 元素不会写入 C Buffer。

## 8. CPU 访问限制

| 条件 | A/BT/C Buffer 访问 |
|---|---|
| `BUSY=0` | CPU 可读写 |
| `BUSY=1` | CPU Buffer 端口被屏蔽 |
| `BUFFER_READY=1` | 可以进行 CPU Buffer 访问 |

控制寄存器在运行期间仍可被 CPU 访问，但当前任务使用的是 `start_ctrl` 已经锁存的参数，运行中修改配置不会改变正在执行的任务。

## 9. 推荐软件访问顺序

```text
1. 写 A Buffer
2. 写 BT Buffer
3. 写 M_CFG/N_CFG/K_CFG
4. 写 TK_CFG
5. 写 QUANT_CFG
6. 写 CTRL.start=1
7. 轮询 STATUS.BUSY，直到变为 0
8. 检查 STATUS.DONE
9. 读取 C Buffer
10. 写 CTRL.clear_done=1
```

## 10. RTL 对应文件

| 功能 | 当前实现 |
|---|---|
| MMIO 请求状态机 | `rtl/top/mmio_if.v` |
| 控制寄存器 | `rtl/top/control_regs.v` |
| 任务生命周期 | `rtl/top/start_ctrl.v` |
| 地址译码和状态读回 | `rtl/top/npu_top.v` 内联逻辑 |
| CPU/NPU Buffer 仲裁和字节屏蔽 | `rtl/top/buffer_access_ctrl.v` |
| Tile 调度、地址生成和 C Tile 写回 | `rtl/ctrl/tile_controller.v` |
| A/BT/C RAM | `rtl/common/npu_ram.v`，由 `rtl/buffer/npu_buffer.v` 复用 |
